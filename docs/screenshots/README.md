# Screenshots

Add demo screenshots here after running the test suite.

## Recommended screenshots to capture

| File name | How to capture |
|-----------|---------------|
| `playwright-report.png` | Run `npm run test:smoke` then `npm run test:report`, screenshot the HTML report |
| `applitools-dashboard.png` | Log in to [eyes.applitools.com](https://eyes.applitools.com) after a run, screenshot the batch results |
| `applitools-diff.png` | Introduce a small UI change, re-run tests, screenshot the visual diff in the Applitools dashboard |
| `bdd-report.png` | Run `npm run test:bdd`, screenshot the HTML report showing Gherkin scenarios |
| `ci-run.png` | Screenshot a passing GitHub Actions run from the Actions tab |

## Tips

- Crop screenshots to focus on the interesting area (test results, diffs, pass/fail badges)
- Use a 1280×720 viewport for consistency
- Annotate with arrows or highlights using a free tool like [Canva](https://canva.com) or [Skitch](https://evernote.com/products/skitch) before posting to LinkedIn
